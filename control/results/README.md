# Control Results

This folder contains the result-processing scripts and the stored outputs from benchmark runs.

## What is here

- `RQ1_RQ2_RQ3-2_calculate_results_image.py` - evaluates model answers against image-ground-truth labels.
- `RQ1_calculate_results_anatomy.py` - evaluates left/right answers against the anatomy reference file and image labels.
- `requirements.txt` - Python dependencies for the result scripts.
- `answers/` - raw JSON answer files grouped by run.
